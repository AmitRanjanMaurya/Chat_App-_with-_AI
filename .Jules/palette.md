## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.## 2024-05-24 - Disabled State Visual Feedback in Jetpack Compose
**Learning:** When using `IconButton` in Jetpack Compose, setting `enabled = false` disables the interaction, but if the inner `Icon` has a custom hardcoded `tint` applied, it won't automatically update to reflect the disabled visual state.
**Action:** Always dynamically adjust the inner `Icon`'s `tint` parameter (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`) based on the same condition used for the `IconButton`'s `enabled` parameter.
