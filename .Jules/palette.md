## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-07-26 - Jetpack Compose TextField Keyboard UX and Disabled IconButtons
**Learning:** In Jetpack Compose, the default software keyboard interactions for `TextField` components are generic. Users have a better experience when the keyboard explicitly supports actions like sentence capitalization (`KeyboardCapitalization.Sentences`) and the 'Send' action (`ImeAction.Send`). Additionally, when an `IconButton` is disabled using `enabled = false`, its inner custom-tinted `Icon` does not automatically update visually to reflect the disabled state unless its `tint` parameter is also dynamically adjusted.
**Action:** When implementing `TextField` components for chat or form inputs, always configure `KeyboardOptions` and `KeyboardActions` to align with the expected user interaction. When explicitly disabling an `IconButton` that uses a custom-tinted inner `Icon`, dynamically set the `Icon`'s `tint` (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`) to ensure the user receives immediate visual feedback that the action is unavailable.
