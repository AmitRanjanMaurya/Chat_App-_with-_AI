## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Soft Keyboard Actions and Visual States in Jetpack Compose
**Learning:** In Jetpack Compose, the `TextField` requires explicit `KeyboardOptions` (like `imeAction = ImeAction.Send`) and `KeyboardActions` to ensure that software keyboards present the correct action key (e.g., Send) and react when pressed. Furthermore, dynamically adjusting an `Icon`'s `tint` based on state provides immediate and crucial visual feedback for disabled `IconButton` components that rely entirely on custom colors rather than default Material styles.
**Action:** Always configure `KeyboardOptions` and `KeyboardActions` for text inputs where a clear terminal action (like sending a message) exists. Ensure that visually custom interactive components explicitly handle their disabled visual state (e.g., via alpha adjustments to tint).
