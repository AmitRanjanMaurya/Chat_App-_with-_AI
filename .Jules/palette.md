## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Enhance TextField UX and Disabled IconButton Visuals
**Learning:** In Jetpack Compose, setting `enabled = false` on an `IconButton` correctly prevents interactions but does not automatically dim a custom-tinted inner `Icon`. Also, configuring `KeyboardOptions` (like `ImeAction.Send`) and `KeyboardActions` greatly enhances intuitive form submission via the software keyboard.
**Action:** When conditionally disabling an `IconButton` to prevent invalid actions (e.g., submitting an empty form), explicitly adjust the inner `Icon`'s `tint` (e.g., to `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`) to provide clear visual feedback. Always configure `KeyboardOptions` and `KeyboardActions` on `TextField`s to improve software keyboard usability.
