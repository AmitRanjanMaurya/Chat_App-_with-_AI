## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Visually disabling Send Button for Empty States
**Learning:** In Jetpack Compose, when an action like sending a message requires valid input (text or image), the trigger button should be visually disabled to prevent user confusion and unnecessary interactions. Hardcoded custom tints on `Icon` do not automatically update, so we must calculate enablement and dynamically update the tint.
**Action:** Calculate valid state combinations (e.g., `text.isNotBlank() || image != null`) and pass the result to the `enabled` parameter of `IconButton`. Conditionally adjust the inner `Icon`'s `tint` using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` for disabled visual feedback.
