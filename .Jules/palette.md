## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.

## 2024-05-24 - Disabled State Tinting & Keyboard UX in Jetpack Compose
**Learning:** In Jetpack Compose, when an `IconButton` is visually customized by setting the inner `Icon`'s `tint` parameter explicitly, that tint does not automatically update to reflect the disabled state of the parent `IconButton`. Additionally, software keyboard features (like sending and capitalization) don't work natively on `TextField`s unless explicitly configured.
**Action:** Always dynamically calculate the inner `Icon`'s `tint` based on the enabled state (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` for disabled). Also, consistently use `KeyboardOptions` (for `ImeAction`, `KeyboardCapitalization`) and `KeyboardActions` on text inputs to ensure a fluid typing experience.
