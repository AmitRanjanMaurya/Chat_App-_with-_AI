## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-06-15 - TextField Software Keyboard Integration and Disabled States
**Learning:** In Jetpack Compose, the `TextField` does not automatically assume enter-to-submit behavior or sentence capitalization. Additionally, standard custom `Icon` tints do not automatically reflect disabled states when the parent `IconButton` is disabled.
**Action:** Explicitly set `KeyboardOptions` (e.g. `ImeAction.Send`) and `KeyboardActions` on `TextField` inputs intended for submission. When an `IconButton` can be invalid (like empty text), dynamically alter the inner `Icon` tint (e.g., `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`) to match the `enabled` state of the parent button.
