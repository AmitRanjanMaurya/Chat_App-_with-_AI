## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.## 2024-05-24 - Jetpack Compose TextField Keyboard UX
**Learning:** In Jetpack Compose, the default `TextField` behavior often forces users to reach up and tap a separate "Send" button on the screen, breaking flow. Additionally, empty states are not clearly communicated if the submit button remains enabled when the input is empty.
**Action:** Always configure `KeyboardOptions` (especially `ImeAction.Send` and `KeyboardCapitalization`) and `KeyboardActions` for chat/input fields to allow submission directly from the software keyboard. Simultaneously, dynamically update the `enabled` state and `Icon` tint of the primary submit button to communicate invalid empty states.
