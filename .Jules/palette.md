## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-07-02 - Disabled State Visual Feedback for Custom Tinted Icons
**Learning:** When using custom colors for `tint` on an `Icon` inside an `IconButton` in Jetpack Compose, simply setting `enabled = false` on the `IconButton` will not automatically dim the icon's color to reflect the disabled state. The custom tint overrides the default state-based coloring.
**Action:** Always dynamically adjust the `tint` parameter of custom-tinted `Icon`s based on the interactive component's `enabled` state (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` for disabled) to ensure clear, immediate user feedback when actions are invalid.
