## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-10-18 - Visual Feedback for Action States
**Learning:** Hardcoded custom tints on `Icon` within an `IconButton` override default disabled states, making the button appear interactive even when `enabled = false`. In GeminiChatbot, the Send button appeared enabled even when the prompt was empty, creating a disjointed user experience where clicks did nothing.
**Action:** When manually setting a custom `tint` on an `Icon` inside an `IconButton`, dynamically check the enabled state condition (e.g., `prompt.isNotEmpty()`) to apply either the active color or a proper disabled color like `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`.
