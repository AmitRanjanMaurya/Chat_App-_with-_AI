## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Disabled State for Send Buttons
**Learning:** Hardcoded custom tints on `Icon` components within an `IconButton` do not automatically update when the `IconButton` is disabled. Furthermore, when disabling buttons that depend on text input, it's crucial to also account for other valid inputs like image attachments to avoid falsely blocking valid user actions.
**Action:** When using `IconButton` with a custom icon tint, dynamically adjust the `tint` parameter based on the enabled state (e.g., `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` for disabled). Always evaluate all valid criteria for enabling a button to prevent regressions.
