## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Enhance TextField UX and Disabled State Accessibility
**Learning:** TextFields should always specify appropriate `KeyboardOptions` (e.g., `KeyboardCapitalization.Sentences` and `ImeAction.Send`) and `KeyboardActions` to ensure intuitive software keyboard interactions. Furthermore, when interactive elements like `IconButton` are disabled based on form state (e.g., empty input), the inner `Icon`'s `tint` parameter must be explicitly adjusted (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`) to clearly communicate the disabled state visually, alongside disabling functional interaction via `enabled = false`.
**Action:** Always configure `KeyboardOptions` for `TextField` inputs, and dynamically update the `tint` of nested `Icon` elements within an `IconButton` to reflect its enabled/disabled state visually.
