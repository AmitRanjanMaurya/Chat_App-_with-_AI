## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Jetpack Compose IconButton Visual Disabled State
**Learning:** When disabling an `IconButton` in Jetpack Compose, if the inner `Icon` has a custom `tint` applied, that tint does not automatically reflect the disabled visual state (e.g., dimming). The button's interaction is disabled, but it still looks enabled.
**Action:** When applying a custom tint to an `Icon` inside an interactive component like `IconButton`, dynamically compute the tint based on the enabled state (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` for disabled, and the standard custom tint when enabled) to ensure clear visual feedback.
