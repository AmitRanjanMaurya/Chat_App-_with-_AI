## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-07-21 - Visual Feedback for Disabled Interactive Elements in Jetpack Compose
**Learning:** In Jetpack Compose, when you disable an `IconButton` using `enabled = false`, the inner `Icon` component will not automatically change its tint to reflect the disabled state if a hardcoded custom tint (like `MaterialTheme.colorScheme.primary`) is applied. The interaction will be blocked, but the button will look active, confusing users.
**Action:** Always ensure that when dynamically disabling interactive elements, you also dynamically adjust their visual properties to reflect the state change. For example, conditionally setting an `Icon`'s tint to a faded color like `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` when disabled.
