## 2024-05-24 - Interactive Component Accessibility in Jetpack Compose
**Learning:** In Jetpack Compose, using `Modifier.clickable` directly on an `Icon` creates an interactive element, but it lacks essential accessibility features like a minimum touch target size (48x48dp) and clear focus semantics. It also fails to provide visual feedback (ripple effect) by default, which can lead to a poor user experience, especially for users relying on assistive technologies or touch interaction.
**Action:** Always prefer the built-in `IconButton` component over an `Icon` with a `Modifier.clickable` for interactive actions. `IconButton` automatically provides a proper touch target size, focus semantics, and visual ripple feedback, ensuring a more accessible and user-friendly experience out of the box.
