## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Disabling Actions and Keyboard Integration in Compose
**Learning:** When disabling an `IconButton` in Jetpack Compose, the inner `Icon`'s custom `tint` parameter does not automatically reflect the disabled visual state. It must be dynamically adjusted (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`). Additionally, standard `TextField`s should integrate software keyboard actions (like `ImeAction.Send`) to improve user workflow, ensuring that these actions are only processed when the overall interaction is valid (e.g., input is not empty).
**Action:** Always dynamically adjust inner icon tints when modifying the `enabled` state of interactive components that override default colors. Additionally, configure `KeyboardOptions` and `KeyboardActions` on text fields corresponding to primary screen actions.
