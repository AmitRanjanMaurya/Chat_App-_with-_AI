## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-10-30 - Visual Feedback for Disabled Actions in Compose
**Learning:** In Jetpack Compose, when an action requires validation (like a non-empty prompt), omitting the `enabled` state on the `IconButton` leads to a confusing UX where clicks appear to be ignored. Furthermore, custom `tint` applied to an `Icon` does not automatically fade when the parent `IconButton` is disabled.
**Action:** Always bind the `enabled` parameter of interactive components to the same validation state used by the action handler, and manually compute the disabled color (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`) for any custom-tinted child elements.
