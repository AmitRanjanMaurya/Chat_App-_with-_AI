## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.## 2024-05-24 - Dynamic Tinting for Disabled Compose Icons
**Learning:** When explicitly setting a custom `tint` on an `Icon` inside an `IconButton` in Jetpack Compose, setting `enabled = false` on the `IconButton` will not automatically dim the icon. The explicitly set tint overrides the default disabled content color provided by the `IconButton`.
**Action:** Always dynamically adjust the `tint` parameter of an `Icon` (e.g., using `if (enabled) PrimaryColor else DisabledColor`) when the enclosing `IconButton` is disabled, to ensure proper visual feedback is communicated to the user.
