## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-06-21 - Visual Feedback for Disabled Interactive Elements in Jetpack Compose
**Learning:** Hardcoded icon colors in Jetpack Compose's `IconButton` do not automatically adapt their visual representation when the button is disabled. If an `Icon` inside an `IconButton` has a custom `tint`, the user won't get visual feedback that the button is unclickable even if `enabled = false` is set on the parent `IconButton`.
**Action:** When disabling an `IconButton` or similar interactive component, dynamically adjust the inner `Icon`'s `tint` parameter based on the same condition used for the `enabled` state (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` for the disabled state) to ensure clear visual feedback.
