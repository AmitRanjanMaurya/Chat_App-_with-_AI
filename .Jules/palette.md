## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-07-10 - Clearer Disabled States and Keyboard Accessibility in Jetpack Compose
**Learning:** When using custom icon colors via `tint` in an `IconButton`, the disabled visual state is not handled automatically by default, requiring the `tint` to be manually adjusted based on `enabled` state (e.g. `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`) for users to perceive it's disabled. Additionally, configuring `KeyboardOptions` and `KeyboardActions` significantly improves form accessibility by providing context-aware software keyboard keys (like "Send") and allowing users to trigger actions without reaching for the physical UI button.
**Action:** Always verify custom-tinted interactive components reflect their `enabled` state visually, and utilize `KeyboardOptions` and `KeyboardActions` to bind software keyboard actions to UI submissions.
