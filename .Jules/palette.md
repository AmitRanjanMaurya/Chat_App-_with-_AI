## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Contextual Keyboard Input and Interactive State in Jetpack Compose
**Learning:** By default, Jetpack Compose `TextField` inputs don't provide useful software keyboard actions like automatic sentence capitalization or a specific 'Send' action key. Furthermore, hardcoding an `Icon`'s custom tint color makes it ignore the enclosing `IconButton`'s disabled visual state, failing to provide crucial visual feedback.
**Action:** When creating text fields for messaging or submission, always configure `keyboardOptions` with appropriate capitalization and `imeAction`, and implement the corresponding `keyboardActions`. Additionally, dynamically compute custom `Icon` tints based on their interaction state to ensure disabled components are visually communicating their state to users (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`).
