## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-06-07 - Dynamic Visual State for Disabled Jetpack Compose Buttons
**Learning:** In Jetpack Compose, setting `enabled = false` on an `IconButton` disables functionality but does NOT automatically adjust the visual tint of a nested `Icon` if that Icon has a hardcoded `tint` (e.g., `MaterialTheme.colorScheme.primary`). This leads to a confusing UI where a disabled button looks fully active.
**Action:** Always dynamically calculate the inner `Icon`'s tint based on the button's enabled state (e.g., using `if (isEnabled) activeColor else disabledColor`, where `disabledColor` is often `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`).
