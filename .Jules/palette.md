## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.## 2024-05-18 - Improve software keyboard behavior and interaction feedback
**Learning:** For chat inputs, the software keyboard's default behavior doesn't optimize for quick message sending. Furthermore, an enabled Send button with an empty input causes empty messages to be submitted or user confusion about form state.
**Action:** Always configure `KeyboardOptions` (with `ImeAction.Send` and `KeyboardCapitalization.Sentences`) and `KeyboardActions` on TextFields for chat/form submission. Couple this by setting the `enabled` attribute on the submission `IconButton` based on input validity, and use `tint` adjustments on the inner icon to make the disabled state visually distinct (e.g., lower alpha).
