## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - TextField Keyboard and Disabled Component States
**Learning:** In Jetpack Compose, an interactive `IconButton` does not automatically update its visual state when its `enabled` property is changed to false if it contains an inner `Icon` with a hardcoded tint. Additionally, users expect the software keyboard to include logical actions like "Send" and sentence capitalization for chat interfaces.
**Action:** Always dynamically adjust the inner `Icon`'s `tint` parameter based on the button's `enabled` state (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` for disabled). Enhance `TextField` UX by configuring `KeyboardOptions` and `KeyboardActions` appropriately.
