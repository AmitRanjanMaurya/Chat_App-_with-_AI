## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Dynamic Styling for Disabled Interactive Icons in Jetpack Compose
**Learning:** In Jetpack Compose, setting the `enabled` flag to `false` on an `IconButton` correctly prevents click actions and satisfies accessibility semantics, but it does NOT automatically update the visual style (like a greyed-out tint) of a nested `Icon` component. Users can be confused if an unclickable button still appears active.
**Action:** When conditionally disabling an `IconButton`, explicitly manage the nested `Icon`'s `tint` parameter using a visual cue like `if (isEnabled) MaterialTheme.colorScheme.primary else MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` to provide accurate visual feedback corresponding to its disabled state.
