## 2024-06-25 - Jetpack Compose TextField Keyboard UX & IconButton State
**Learning:** In Jetpack Compose, an `IconButton` does not automatically update its inner `Icon`'s tint when its `enabled` state changes, requiring manual tint adjustment (e.g., `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`) for proper visual feedback. Additionally, `TextField` components in chat apps greatly benefit from explicit `KeyboardOptions` (`ImeAction.Send`, `KeyboardCapitalization.Sentences`) and `KeyboardActions` to connect the software keyboard's primary action directly to the app's send logic.
**Action:** When implementing chat inputs or forms in Compose, always explicitly bind the software keyboard actions and ensure that when disabling an `IconButton`, the inner `Icon`'s tint is explicitly managed to reflect the disabled state.
