## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Dynamic Tinting for Disabled Compose Icons
**Learning:** When disabling an `IconButton` in Jetpack Compose, the inner `Icon` does not automatically fade or update its `tint` parameter if you are using a custom tint (e.g., `MaterialTheme.colorScheme.primary`). This can lead to a UI where the button looks enabled but doesn't do anything, causing user confusion.
**Action:** When using a custom tint on an `Icon` inside an interactive component, always dynamically check the interactive/enabled state to assign the correct color. E.g., `tint = if (isEnabled) MaterialTheme.colorScheme.primary else MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)`.
