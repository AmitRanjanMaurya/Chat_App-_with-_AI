## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-08-28 - Explicit Disabled States on Custom Tinted Icons
**Learning:** When disabling an `IconButton` in Jetpack Compose, dynamically adjusting the inner `Icon`'s `tint` parameter is necessary because hardcoded custom tints do not automatically reflect the disabled visual state, leading to a confusing UX where inactive buttons appear active. Also, when determining the enabled state (e.g. for a Send button), we must consider all valid states (like an image attachment) to prevent incorrectly blocking valid user actions.
**Action:** Use a dynamic color logic like `if (enabled) MaterialTheme.colorScheme.primary else MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` when tinting icons inside interactive elements to explicitly convey their state, and ensure the enabled check accounts for multiple valid input paths.
