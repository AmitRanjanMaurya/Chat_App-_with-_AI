## 2024-05-24 - Accessible Interactive Icons in Jetpack Compose
**Learning:** Using `Modifier.clickable` on an `Icon` component in Jetpack Compose does not automatically provide the necessary minimum touch target size (48x48dp) or visual feedback (like a ripple effect) required for good accessibility and UX.
**Action:** Always prefer wrapping `Icon` components with an `IconButton` when they are meant to be interactive. `IconButton` built-in defaults satisfy accessibility touch targets and provide focus semantics and ripple effects out of the box.
## 2024-05-24 - Visual Disabled State for IconButton in Jetpack Compose
**Learning:** Hardcoded tints for `Icon` components inside an `IconButton` override the default visual disabled state, leading to a disabled button that still looks active. Furthermore, users could accidentally submit blank prompts if `isNotEmpty()` is used instead of `isNotBlank()`.
**Action:** When conditionally disabling an `IconButton` containing an `Icon` with a custom tint, dynamically adjust the `tint` parameter based on the enabled condition (e.g., using `MaterialTheme.colorScheme.onSurface.copy(alpha = 0.38f)` for the disabled state). Use `isNotBlank()` for text validation to prevent whitespace-only submissions.
